If that server runs on this same host, change CENTRAL_URL to https://localhost:{{ central_port }} — a cloud instance usually cannot reach its own public address. Self-signed certificate? Also set CENTRAL_VERIFY_TLS to the certificate's path, which pins the agent to it and keeps verification on. CENTRAL_MANAGED = True additionally moves that instance's login to Central — turn it on only after check-ins work. See CENTRAL.md.
