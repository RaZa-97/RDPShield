Each IP is scored 0–100 by a model trained on this server's own attack history. The score estimates how closely an IP's behaviour + reputation matches IPs the rule engine has flagged.

A high score on an IP the rules never blocked is the interesting case — a low-and-slow attacker worth a manual look.
